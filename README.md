#  Cocoon Classification

A web application and machine learning pipeline for **classifying silk cocoons** using a trained deep learning model.  
This project combines **Python (Flask)** for the backend with a **JavaScript + HTML/CSS** frontend to provide a seamless user experience.

---

##  Features
- **Cocoon Image Classification** – Predicts the category of a cocoon using a pre-trained PyTorch model.
- **Interactive Web Interface** – Simple UI for uploading images and viewing results.
- **Model Integration** – Uses `.pth` and `.pt` files for classification tasks.
- **Price Estimation (Optional)** – Includes `price.js` for cocoon-related pricing logic.
- **Responsive Design** – Clean CSS styling for smooth usage across devices.
